# ShareRoom

Share your screen, talk and chat with friends — no sign-up, no downloads.

**Open it:** https://lennonhiew.github.io/shareroom/

1. Type your name and press **Start a room**.
2. Press the room code at the top to copy an invite, and send it to your friends.
3. Friends open the link (or enter the code) and they're in.

Features: multiple people sharing screens at once, voice chat with push-to-talk, chat with images and files,
emoji reactions, laser pointer and drawing on shared screens, screenshots, recording, picture-in-picture,
and it installs as an app (look for **Install app**).

It connects friends directly with WebRTC via [PeerJS](https://peerjs.com/), so it works best for about 2–6 people.
Screen sharing needs Chrome, Edge or Firefox on a computer; phones can watch, talk and chat.
